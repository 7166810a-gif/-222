# WiFi Control for Android

אפליקציית Android לסריקת רשתות Wi-Fi, בחירת רשת וניסיון התחברות ישירות מתוך האפליקציה.

## מה האפליקציה עושה

- סורקת נקודות גישה בטווח ומציגה SSID, סוג אבטחה, עוצמת אות ותדר.
- מאפשרת לבחור רשת ולהזין סיסמה.
- במכשיר עם Root והרשאת Superuser, מנסה להפעיל/לכבות Wi-Fi ולהתחבר לרשת באמצעות פקודות מערכת.
- ללא Root, משתמשת ב-`WifiNetworkSuggestion` ב-Android 10 ומעלה. זו הצעה למערכת, לא התחברות כפויה; Android מחליטה אם ומתי להתחבר ועשויה לבקש אישור.
- בגרסאות Android ישנות יותר קיים מסלול התחברות Legacy, הכפוף למגבלות הגרסה והיצרן.

## מגבלות חשובות

- Android 10 ומעלה חוסם מאפליקציה רגילה הפעלה/כיבוי ישירים של Wi-Fi. ניסיון Root יעבוד רק אם המכשיר rooted, המשתמש אישר Superuser והפקודות הנתמכות תואמות לגרסת המכשיר.
- תוצאות סריקה מחייבות הרשאת מיקום מתאימה ושירותי מיקום פעילים, והן כפופות להגבלת תדירות הסריקות של Android. האפליקציה לא עוקפת את ההגבלות.
- התחברות ללא Root אינה מובטחת כמיידית או שקטה. Android שולטת בבחירת הרשת ובהצגת בקשות האישור.
- תמיכת WPA3 בהצעת רשת דורשת Android 10 (API 29) ומעלה.

## דרישות בנייה

- JDK 17
- Gradle 8.9
- Android SDK Platform 35
- Android Build Tools 35.0.0

לבנייה מקומית, מתוך תיקיית הפרויקט:

```bash
gradle --no-daemon assembleDebug
```

קובץ ה-APK יופיע בנתיב:

```
app/build/outputs/apk/debug/app-debug.apk
```

## בניית APK אוטומטית ב-GitHub

הקובץ `.github/workflows/android-build.yml` מגדיר GitHub Actions:

1. כל Push ל-`main` או `master` מפעיל בנייה.
2. אפשר להפעיל בנייה ידנית בלשונית **Actions** באמצעות **Build Android APK** ו-**Run workflow**.
3. בסיום מוצלח, פותחים את ריצת ה-build ומורידים את ה-Artifact בשם `wifi-control-debug-apk`.

זהו APK מסוג Debug המיועד להתקנה ובדיקה. הוא אינו APK חתום להפצה בחנות.

## התקנה ובדיקת Root

1. התקן את ה-APK במכשיר Android (גרסה 8.0 ומעלה).
2. אשר את הרשאת המיקום המדויקת כשמתבקשת. היא נדרשת לקריאת תוצאות סריקת Wi-Fi.
3. הפעל שירותי מיקום ו-Wi-Fi, ואז לחץ על **סרוק רשתות Wi-Fi**.
4. בחר רשת, בחר את סוג האבטחה והזן סיסמה לפי הצורך.
5. במכשיר rooted, אשר לאפליקציה הרשאת Superuser כאשר מנהל ה-Root יבקש זאת.

אל תשתף סיסמאות Wi-Fi או פרטי גישה ב-Issues או בלוגים ציבוריים.
